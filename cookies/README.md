# YouTube Cookies Setup

To bypass YouTube's bot detection, you can provide cookies from your browser.

## Method 1: Export cookies from browser (Recommended)

1. Install a browser extension like "Get cookies.txt LOCALLY"
2. Go to YouTube and make sure you're logged in
3. Export cookies for youtube.com
4. Save the cookies file as `youtube_cookies.txt` in this directory

## Method 2: Automatic browser extraction

The bot will automatically try to extract cookies from:
- Chrome
- Firefox  
- Safari
- Edge

Make sure you're logged into YouTube in at least one of these browsers.

## Method 3: Manual cookie string

Create a file named `youtube_cookies.txt` with your cookies in Netscape format.

## Security Note

Never share your cookies file publicly as it contains your authentication data.
